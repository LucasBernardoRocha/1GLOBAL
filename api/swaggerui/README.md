# Swagger UI assets

Vendored from `swagger-ui-dist@5.34.1` so the API documentation is served from
the binary and works without network access.

Only the files required by `api/swaggerui/index.html` are kept here:

- `swagger-ui-bundle.js`
- `swagger-ui.css`
- `favicon-32x32.png`

Source: <https://www.npmjs.com/package/swagger-ui-dist>

To upgrade, download the npm tarball for the desired version and replace the
files above. Keep the version in this note in sync.
